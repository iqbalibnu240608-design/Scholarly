# Spacing System

Use a consistent spacing scale based on a 4px or 8px rhythm, selected after inspecting the existing codebase.

Document:
- Base spacing tokens.
- Container widths and page gutters.
- Section spacing for public pages.
- Density rules for dashboards and tables.
- Component padding and gaps.
- Breakpoints and responsive adaptations.

Landing pages may use generous whitespace; operational dashboards should use controlled density without feeling cramped.
