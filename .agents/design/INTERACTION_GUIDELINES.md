# Interaction Guidelines

Specify interaction contracts for navigation, forms, filters, tables, charts, dialogs, notifications, and destructive actions.

- Provide visible hover, focus, active, disabled, loading, success, and error states as applicable.
- Ensure keyboard navigation and visible focus.
- Use concise feedback close to the action.
- Confirm destructive or irreversible actions.
- Avoid unnecessary animation; respect reduced motion.
- Never use fake loading or success states to disguise missing functionality.
