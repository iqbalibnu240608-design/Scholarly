# Component Guidelines

Define reusable components only where repeated behavior or visual consistency justifies them.

For each component document anatomy, variants, states, responsive behavior, keyboard support, and accessibility:
- Buttons and icon buttons.
- Inputs, selects, checkboxes, and form validation.
- Header, sidebar, breadcrumbs, tabs, and mobile navigation.
- Cards and statistic summaries.
- Data tables, filters, pagination, and sorting.
- Charts and data visualizations.
- Dialogs, drawers, dropdowns, tooltips, and toast notifications.
- Loading skeletons, empty states, error states, and permission states.

Every visible control must have a real behavior or be clearly presented as non-interactive content.
