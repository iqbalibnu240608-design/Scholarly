# Typography

## Direction
Choose a modern, highly legible sans-serif suitable for both a polished landing page and dense application interfaces.

## Required specification
- Font family and source/licensing.
- Display, heading, body, label, caption, and code styles.
- Font sizes, weights, line heights, and letter spacing.
- Responsive scaling for mobile/tablet/desktop.
- Fallback stack and loading strategy.

## Usage
Use expressive display typography only for marketing/hero contexts. Application dashboards should prioritize scanability, consistent labels, and comfortable reading sizes.
