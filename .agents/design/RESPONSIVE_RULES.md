# Responsive Rules

Design and verify mobile, tablet, laptop, and wide desktop layouts.

- Public landing pages: stack hero content cleanly on small screens; keep CTA visible and avoid clipped product mockups.
- Dashboards: collapse sidebar into accessible mobile navigation; preserve critical metrics and table actions.
- Tables: use responsive columns, horizontal scrolling only when appropriate, or switch to a compact row/card presentation.
- Forms: use touch-friendly controls and clear validation.
- Images and charts: scale without distortion and retain readable labels.
- Test real viewport sizes; do not rely on CSS appearance alone.
