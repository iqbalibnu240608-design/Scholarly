# Visual Direction — Competition Project

## Purpose
Guide the project's visual theme so the interface feels cohesive, modern, polished, and suitable for a school competition. These references guide visual style only; they are not a specification of product features or architecture.

## Reference roles
- **Novus:** premium landing-page composition, confident typography, generous whitespace, soft blue/lavender atmosphere, gradient accents, and a strong hero visual.
- **Flowize AI:** modern SaaS presentation, clean blue-and-white palette, floating product preview, restrained metrics, and clear visual hierarchy.
- **NexaAdmin:** professional admin interface, structured sidebar, top navigation, data tables, charts, status indicators, and consistent module layouts.

## Overall visual direction
- Modern, clean, professional, elegant, and approachable.
- Blue/indigo as the primary visual family, with white and cool neutral surfaces.
- Lavender/purple may be used as a restrained secondary accent where it supports the brand.
- Use gradients sparingly for emphasis, not as a background on every section.
- Use subtle shadows, borders, and rounded corners consistently.
- Strong typographic hierarchy; readable body and interface text.
- Keep whitespace generous on landing pages and use efficient, readable density in dashboards.

## Apply by page type
- Landing/public pages: use Novus as the main composition reference.
- Overview/product dashboards: use Flowize AI for visual hierarchy, metrics, and product storytelling.
- Admin/data-management pages: use NexaAdmin for navigation, tables, charts, and operational clarity.
- Do not force every page into the same layout. Adapt to the actual purpose and user workflow discovered in the project.

## Important boundaries
- Do not assume the project is an AI platform, LMS, school portal, or admin product based only on the references.
- Do not invent features, metrics, integrations, user roles, or page content.
- Do not copy reference logos, names, exact text, proprietary assets, or pixel-identical layouts.
- Preserve the product's existing identity and functionality unless the owner approves a change.
