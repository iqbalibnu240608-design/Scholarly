# UI/UX Guidelines

Derive information architecture from confirmed user roles and real workflows.

- Prioritize the user's most frequent and important tasks.
- Separate public marketing pages from authenticated application areas when both exist.
- Use navigation labels that match user language.
- Keep page titles, breadcrumbs, and primary actions predictable.
- Include loading, empty, error, success, validation, permission-denied, and not-found states.
- Make accessibility and responsive behavior part of implementation, not a final polish step.
- Avoid unnecessary dashboard widgets and decorative sections that do not support a user task.
